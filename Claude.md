## projeto para registar treino de séries

## Introdução

    Este projeto destina-se a atletas que fazem atletismo, corridas, corrida com barreiras, ou outras e que querem registar os seus treinos em pista.

    - Numa primeira fase vamos testar apenas com atletas de meio fundo

    - Esta aplicação deverá correr na Internet, deverá ter uma interface simples e intuitiva, acessivel a uma comunidade do atletismo e a nivel mundial.

    - Em termos técnicos o site deverá ser alojado num servidor WEB com linux, a linguagem a sr utilizada será php no servidor, no front end será html, css e javascript, os dados serão armazenados num base de dados Mysql

## Capacidades da aplicação

    - Registo de utilizador login com gmail e email e password
    - possibilidade de alterar password, dados pessoais, email, nome a apresentar, avatar, peso, altura e outros.
    - Registar tempos para cada repetição, imagina um treino de 10 * 500m com 70 segundos de descanso, no dia x e no local b, ás tantas horas. possibilidade de carregar ficheiro gpx.
    - Poder ver-se os treinos realizados, filtrando por distancia, mês, ano, etc
    - Um dashboard com metricas do que já realizou, melhores tempos, distancias mais realizadas, etc.
    - Outras que achares interessantes.
    - Tenho localmente o xampp instalado, podes fazer os teste que quiseres.
    - Usa skills de web designer e outras que achares importantes
